# Job Attachments Workflow

## Purpose

Keep all job-related files accessible from the job rather than scattered across email, local folders, and unrelated systems.

## Current workflow

A Files action opens a job-specific attachment panel.

The panel supports:

- selecting multiple files
- uploading
- viewing existing files
- opening files
- removing files

## Planned improvement

Replace the plain picker with a professional drag-and-drop zone designed for uploading an entire job packet at once.

The target workflow:

1. Open job Files.
2. Drag all relevant files into the panel.
3. Review the staging list.
4. Optionally classify files.
5. Upload the complete batch.
6. See per-file success or error feedback.

This means bulk upload to one job, not attaching one file to multiple jobs.
