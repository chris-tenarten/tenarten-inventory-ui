# Job Forms

## Purpose

Demonstrate and eventually provide job-linked document generation.

## Current placeholders

- Quote
- Letter of Transmittal

These names reflect forms already used by the business.

## Current status

The feature is a proof-of-concept only.

It communicates the intended future capability:

- open a template
- prepopulate known job data
- allow remaining fields to be edited
- generate or print the resulting form

No real generation, persistence, or template system should be assumed yet.
