# Shared UPDATE expiration candidate

Baseline: `8f549d57bdfad25355787ccf0f3788436f38b23e`; branch `fix/announcement-expiry`. Local candidate only; no push, merge or deployment.

Investigation found no prior expiration fix in reachable component history or inspected existing local worktree copies. The 888 ms release did not include one. Desktop and mobile use the same PerformanceAnnouncement component. Its existing deadline timer lacks visibility/focus/pageshow revalidation, allowing a suspended page to retain stale visibility until its timer is serviced. Dismissal is also captured in the effect and local dismissal does not update it.

The component now rechecks the existing wall-clock window and persisted dismissal on visible/focus/pageshow, replaces the pending deadline timer, and removes listeners on unmount. A page-local dismissal ref preserves dismissal even when browser storage is blocked. Expiry hides both trigger and open popover. Activation, seven-day duration, exclusive expiry boundary, preview behavior and storage keys are unchanged. The configured expiry is October 21, 2026 at 23:07 UTC; desktop absence by itself does not establish expiry (it may reflect dismissal or browser clock). No actual device diagnosis is claimed.

Each case checked trigger/popover disappearance, retained application shell, no startup replay and no extra auth requests. No page exceptions or unexpected external requests; backend intercepted, no hosted writes. Validation used existing Playwright/browser fixtures, not a new framework.
